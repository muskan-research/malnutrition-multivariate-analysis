# Public release checklist

Before adding new material to this repository:

1. Confirm that no raw patient data, unique patient identifiers, hospital identifiers, dates of service, or other direct or indirect identifiers are included.
2. Keep the clinical analysis dataset outside the public repository.
3. Use command-line arguments or relative paths rather than local absolute paths.
4. Keep manuscript-specific results consistent with the final analysed dataset and version of the code.
5. State the manuscript status and citation information once finalised.
6. Add a formal software/data license only after confirming that the repository contents can legally be released under that license.
7. If a DOI is created, add it to the README and a citation file.
