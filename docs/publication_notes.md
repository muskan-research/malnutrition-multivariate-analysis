# Public release notes

Before making the repository public:

1. Confirm that no raw patient data, unique patient IDs, hospital identifiers, dates of service, or private labels are committed.
2. Keep the exact analysis dataset outside the repository.
3. Replace any local absolute paths with command-line arguments or relative paths.
4. Keep final manuscript numbers in the manuscript/repository release rather than scattering them through source-code comments.
5. Add a citation, affiliation, manuscript status, and license when these are final.
6. If the repository is associated with a submitted manuscript, state the manuscript status in the README.
